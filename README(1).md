# Project 1 - Photo Scavenger Hunt

Submitted by: **Julian Lesesne**

**Photo Scavenger Hunt** is an iOS app that lets users complete a list
of photo-based scavenger hunt tasks. Users can select a photo for a
task, view the photo's location on a map, and see which tasks have been
completed.

Time spent: **TBD**

## Required Features

The following **required** functionality is completed:

-   [ ] App displays list of hard-coded tasks
-   [ ] When a task is tapped it navigates the user to a task detail
    view
-   [ ] When user adds photo to complete the tasks, it marks the task as
    complete
-   [ ] When adding photo of task, the location is added
-   [ ] User returns to home page (list of tasks) and the status of your
    task is updated to complete

The following **optional** features are implemented:

-   [ ] User can launch camera to snap a picture

The following **additional** features are implemented:

-   [ ] None
